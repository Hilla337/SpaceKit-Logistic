# SpaceKit Logistic

Мини-приложение в Telegram для склада (Володя) и курьеров SpaceKit.

**Как это работает**
1. Заявка попадает в «Новые заявки». Если объект уже знаком, курьер подставляется сам. Новый объект Володя закрепляет за курьером один раз.
2. Заявки копятся в «рейсе на погрузку» курьера. Володя выставляет порядок объезда, приложение показывает порядок погрузки (с конца).
3. «Отправить рейс» — курьер получает список в боте.
4. Курьер видит одну точку за раз: адрес, груз, окно клиента, кнопку навигатора.
5. «Отчёт в бот» — бот просит фото и видео. Курьер снимает обычной камерой Telegram (файлы догружаются сами, когда появится связь). Как только есть фото и видео, точка закрывается, открывается следующая.
6. Каждый отчёт уходит в группу «SpaceKit · Доставки», в тему своего объекта, с подписью: объект · заказ · груз · курьер · время.
7. «Проблема на точке» — причина и комментарий сразу уходят Володе и в тему объекта, курьер едет дальше.

**Где что работает**
- Страница и сервер — Яндекс Облако (API Gateway + Object Storage + Cloud Functions), база — YDB serverless. Из России открывается без замедлений.
- Код — здесь. Каждый пуш в `main` проверяется тестами и сам выкладывается (`.github/workflows/deploy.yml`).

**Первый запуск**
1. Секреты репозитория (Settings → Secrets and variables → Actions): `YC_SA_KEY`, `YC_FOLDER_ID`, `TG_BOT_TOKEN`.
2. Запустить выкладку (Actions → «Выкладка в Яндекс Облако» → Run workflow).
3. Первым открыть бота и нажать /start — тот, кто сделает это первым, становится владельцем (склад).
4. Добавить бота в группу админом, включить «Темы», написать в группе `/reports`.
5. Курьеры и Володя открывают бота → /start → подтвердить их во вкладке «Люди».

**Локально**
`node --test test/*.test.js` — тесты логики.
Открыть `web/index.html` вне Telegram — включится демо-режим с тестовыми данными (предварительно `cp shared/core.js web/core.js`).

Структура: `shared/core.js` — вся логика (одна для сервера и демо), `function/` — Cloud Function, `web/` — страница, `deploy/gateway.yaml` — маршруты.
